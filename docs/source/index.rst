

===============
Slider for HTML
===============

Increase your user interactive experience. This is the chance for the user to change
elements simply by using their mouse or touch screen, without the need to type
in values.

Changing values can be shown, but the best feedback is the change that can be seen.

Start from scratch and learn along the way.
